# 桌面宿主说明

玩家安装与联机流程见 [玩家指南](../docs/一键联机与完整安装包.md)，构建步骤见 [开发与构建](../docs/开发与构建.md)。

Electron 启动本机 Node 服务并加载竞技场界面。完整发行包检测 `runtime/manifest.json` 后使用内置 Forge/JDK；远程对局连接所选服务器，规则运行在主持者电脑。

渲染窗口启用沙箱、上下文隔离并关闭 Node 集成。牌组读写和公网隧道仅通过受限 preload 接口调用。Quick Tunnel 仅代理宿主自己的回环服务，退出软件时停止。

用户牌组和运行配置放在 Electron 用户数据目录，Forge 会话放在其中的 `forge-sessions`。安装器升级保留用户数据。开发宿主可通过 `FORGE_WORKSPACE_ROOT` 和 `JAVA_HOME` 指向外部运行库。

自动启动检查：设置 `MTG_DESKTOP_SMOKE` 为输出 JSON 路径，`MTG_TEST_PROFILE` 为专用测试目录，再运行打包后的 exe。检查页面、健康接口和牌组持久化后自动退出。不得使用真实用户目录。该检查不能替代 Java 对局或安装器安装验证。
