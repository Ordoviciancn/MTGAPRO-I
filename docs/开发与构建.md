# 开发与构建

## 开发环境

使用 Windows、Node.js 22、pnpm、Git、Eclipse Temurin JDK 17。运行 `pnpm install --frozen-lockfile` 安装依赖。

```powershell
.\scripts\检查Forge环境.ps1
.\scripts\构建Forge核心.ps1 -JdkHome '<Temurin JDK 17 目录>'
pnpm dev
```

Forge 版本固定在 `config/forge-source.json`。源码、Maven 与依赖在 `.local-tools/`，不提交这些缓存。

## 验证

提交前运行 `pnpm test` 和 `pnpm build`。真实规则联机使用：

```powershell
$env:JAVA_HOME='<Temurin JDK 17 目录>'
pnpm forge:network-smoke
pnpm forge:network-smoke --card-target
pnpm forge:network-smoke --manland
pnpm forge:bo3-smoke
```

这些夹具分别覆盖网络施法与重连、卡牌目标、地活化与 BO3；通过不代表全卡池所有交互已验证。`forge:probe` 仅验证 Node/Java 桥接环境。

## 完整安装包

准备 `.local-tools/cloudflared/cloudflared.exe` 及同目录 `manifest.json`、许可证，清单中的 SHA256 必须与程序一致。发布时保留固定版本与来源记录。

```powershell
$env:JAVA_HOME='<Temurin JDK 17 目录>'
pnpm desktop:bundle
pnpm desktop:installer
```

`desktop:bundle` 输出 `release/MTGAPROⅠ-win32-x64/`，内含 Forge、对应源码及许可证、JDK legal 目录与 Cloudflared。`desktop:installer` 将该目录封装为 `release/installer/MTGAPRO-I-Setup-<版本>.exe`。版本取自根 `package.json`。安装器暂未签名。

`desktop:build` 供开发迭代，不代替完整运行库构建。发布时只上传安装器及校验文件到 GitHub Release，不把二进制、构建缓存或用户数据提交到源码仓库。

## 公网验证

在桌面程序开启隧道后，将地址设为 `FORGE_PUBLIC_URL`，运行 `pnpm exec tsx scripts/forge-public-smoke.ts`。它通过公网 HTTPS/WSS 验证两座位对局，但不等同于两台异地物理机实测。
