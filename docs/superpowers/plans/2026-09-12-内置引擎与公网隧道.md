# 内置引擎与公网隧道实施规划

目标：玩家安装单个 Windows 安装程序后，无需配置 Java、Forge、Git 或服务器，能在本机主持并邀请公网对手。

架构：Electron 发行程序包含可搬移 Forge/JDK/资源与 Cloudflared；Node 启动内置 Java，所有会话写入用户目录。桌面受限 IPC 管理仅指向自身服务的 Quick Tunnel，网页不能任意启动进程或代理端口。

用户已明确选定本机规则服务、Cloudflare Quick Tunnel、全量运行库打包，并授权直接推进。安装器方案保留程序到固定目录，避免每次启动解压完整 JDK 和牌库；不要求玩家手动安装依赖。
