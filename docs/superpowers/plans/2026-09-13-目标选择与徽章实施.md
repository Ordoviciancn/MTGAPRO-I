# 目标选择与徽章 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复牌对象目标选择被误判为异能选择的卡死，并制作无人物的 MTGA 风格徽章。

**Architecture:** Forge 的强、弱可选对象在 Java Bridge 内独立保存，状态投影时合并为当前输入唯一的 `actionable` 集合。React 只发送被服务端标记为可操作的牌；徽章继续使用纯 SVG/CSS，不参与规则状态。

**Tech Stack:** Java 17、Forge、TypeScript、React、SVG、CSS、Node test runner

## Global Constraints

- Forge 是唯一规则权威。
- 不从快照推断隐藏信息或规则结果。
- 徽章交互不得改变其几何位置。
