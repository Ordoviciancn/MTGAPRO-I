# 中文资源与对局动效

## 接入约定

中文资源使用大学院废墟公开 API `https://mtgch.com/api/v1/result`，文档为 `https://mtgch.com/api/v1/docs`。按英文名称查询后再次核对完整名称或双面牌面名称；不采用搜索结果第一项。中文印刷文本、社区翻译保留来源说明，缺失时显示英文。

资源查询仅发生在客户端可见的卡牌上，不能查询对手未公开手牌。请求去重、限速、缓存，并允许失败回退。中文资源不替换 Forge 内部名称、目标引用或选择值。规则提示优先启用 Forge 原生 zh-CN 语言包。

## 表现层

牌库使用 CSS 层叠与透视。抽牌、施放、区域移动使用真实语义事件驱动的卡牌飞行；战斗宣告与伤害命中分开表现。胜负直接读取 Forge 结果，不根据生命值推测。保留减少动态效果偏好，后台页面不补播积压动画。

## 实施与验证

- 中文资源匹配与隐藏信息回退测试。
- 接入所有牌桌卡图、堆叠、拖拽及预览；展示中文参考文本。
- 扩展战斗和终局投影，验证真实 Forge 中文开局、施法、战斗及终局。
- 动画保持正常结算时点，不修改游戏状态，不延迟玩家响应。

动效节奏依据 `录屏交互观察.md`。此实现不声称与 MTGA 逐帧一致，也不将社区翻译标为官方内容。
