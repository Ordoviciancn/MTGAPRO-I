## 动效与时长边界

连续片段以每秒 1–2 帧抽样，时间码允许约 0.5–1 秒偏差。这足以确认状态顺序，不能用于声称 150 ms 或 300 ms 的真实动画时长。观察到大多数卡牌姿态切换发生在相邻采样之间，而堆叠、选择窗和目标线可持续多秒，后者明显受用户与对手决策影响。

初版可采用以下设计参数，均为实现建议、不是录屏测量值：悬停抬升 120–180 ms；手牌重排 180–240 ms；出牌移动 280–420 ms；横置 160–240 ms；付费流光 350–550 ms；入场/受伤反馈 250–500 ms；回合横幅 900–1400 ms。动画不持有规则权威，不用固定延时替代优先权或结算确认。

## 状态结构建议

保留 `idle / handPreview / casting / choosingMode / choosingTarget / paying / waitingPriority / resolving / choosingCards` 等互斥输入状态，并叠加当前回合、阶段、堆叠和攻击/阻挡标记。合法手牌使用青边，确认中的卡使用金色强调；右下按钮由可执行动作决定，不统一写成“下一步”。只有规则层允许的目标可成为曲线端点。

## 未验证项

手牌实现采用按数量对称展开的扇形、150 ms 悬停放大和 220 ms 重排补位。预览保持牌面比例，独立于真实手牌布局且不接收鼠标事件；拖拽结束、失焦、滚动、窗口变化和 Esc 均收起预览。上述时长为设计参数，尚未与 MTGA 逐帧对齐。浏览器验证覆盖七张手牌、Esc 收起、手牌拖入堆叠与手牌重排。

- 采样图像不能证明用户采用鼠标拖拽、双击还是单击出牌，也不能证明悬停延迟阈值。
- 未完整核验阻挡者分配、多目标、伤害分配、反击咒语以及堆叠多层交互，不应据此宣称这些行为已经复刻。
- 牌面文字较小，本文不将无法辨认的具体卡牌效果作为规则规格。
- 总览每 20 秒抽一帧，默认采样接近区间中部，不能直接把第 n 帧当作 `(n-1)×20` 秒；上述时间使用直接 seek 的细分采样。
