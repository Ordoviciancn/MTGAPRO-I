# 一键联机与完整安装包

## 玩家使用

运行 `MTG-Simulator-Setup-0.1.6.exe` 安装程序，选择安装位置，之后从桌面快捷方式启动。完整包包含 Forge、Temurin JDK 17、Cloudflared 和界面资源，不需要玩家安装 Git、Maven、Node 或 Java。卡牌图片仍通过网络按需加载。

主持者在大厅点击“开启公网联机”，待邀请地址出现后复制给朋友。主持者连接本机服务器并创建房间；对手把邀请地址填入服务器地址框，点击连接，再从房间列表加入。双方可以选择各自保存的牌组。

对局中也可通过顶部应用菜单“公网联机”复制地址或关闭入口。关闭主持软件或入口会断开公网对手。Quick Tunnel 每次启动分配临时地址，不需要 Cloudflare 账户、域名或端口转发；它不是永久在线大厅，且不承诺可用性。

## 数据保存

牌组保存在 Electron 用户数据目录，规则会话存放在其中的 `forge-sessions`，安装目录不写入对局数据。升级安装包时保留用户数据。对局目前保存在内存，重启不能恢复正在进行的规则状态。

本项目只保留 Forge 桌面客户端。旧手动网页已移出项目，不随源码或安装包分发。

## 构建者

先准备固定版本 Forge 开发构建、Temurin JDK 17，以及经过校验的 `.local-tools/cloudflared`。执行：

```powershell
$env:JAVA_HOME='D:/Program Files/JDK'
pnpm desktop:bundle
pnpm desktop:installer
```

安装器位于 `release/installer/`。`desktop:bundle` 把运行库复制为相对路径并附带 Forge 对应源码与许可证、JDK legal 目录；`desktop:installer` 将已完成的发行目录封装为单文件安装器，不会自动上传或发布。安装器尚未进行代码签名。

公网路径验证：设置 `FORGE_PUBLIC_URL` 为邀请地址，运行 `pnpm exec tsx scripts/forge-public-smoke.ts`。脚本经 HTTPS/WSS 创建两个客户端、执行真实 Forge 起手和出地并检查隐藏信息。此测试不等于两台异地物理设备验收。

Cloudflare 文档：https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/

首次安装会解压大量 Forge 规则与 Java 文件，可能需要数分钟；等待安装程序完成后再启动客户端。发行目录直启、安装器安装和公网对局分别验证，不能以其中一项替代其他项。
