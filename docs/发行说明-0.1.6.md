# MTG Simulator 0.1.6

Windows x64 正式版，更新日期：2026-09-15。

## 对局与界面

- 首局由 Forge 随机分配先后手，无骰子或硬币动画。BO3 后续对局由上一局败者选择先后手。
- 战场展示指示物、装备与灵气的贴附关系。
- 展示规则允许查看的牌库顶；特殊区域可施放卡牌通过独立入口操作。
- 大量候选项支持搜索筛选，操作栏可最小化。
- 优化中文卡名与卡图加载进度、失败重试及衍生物图片回退。
- 保留牌组本地保存、房间联机、堆叠与最近结算记录。

## 安装

下载 `MTG-Simulator-Setup-0.1.6.exe` 并运行。完整包内置 Forge、Temurin JDK 17 和 Cloudflared，无需另外安装 Java 或 Node.js。卡图和公网隧道需要网络连接。

`SHA256SUMS.txt` 用于核对安装包完整性。

## 验证范围

- 50 项自动测试通过，TypeScript 类型检查和前端构建通过。
- 真实 Forge 回归覆盖 BO3 换备、牌库顶展示、返照、传纪章节选择与装备贴附。
- 实际打包 EXE 使用内置运行库通过同机双座位开局、出地及对手手牌隐藏验证。
- 上述用例不代表全卡池机制全部验证，也不等同于异地双物理机网络验收。
