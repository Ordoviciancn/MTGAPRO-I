# 堆叠展示验收

- 堆叠使用独立面板，卡牌以 180×252 像素显示，窄屏以 160×224 像素显示，维持原始比例。
- 咒语和异能显示来源、类别与 Forge 效果文本。进入堆叠时显示滑入过渡，减少动态效果偏好下关闭过渡。
- 服务器按座位保存最近 16 条释放与结算事件。自动让过、快速结算和动画清空不会删除这些记录；重连返回相同可见记录。
- 堆叠清空后保留最近事件的大卡图，用户可展开历史阅读更早事件。未公开来源不请求真实卡图，也不显示隐藏效果文本。
- 真实 Forge 施法、重连记录、米斯拉的工厂活化异能、Shock 指向生物回归通过。
- 视觉浏览器接口因本机运行时路径错误不可用，尚未完成真实浏览器截图验收；组件构建检查不能代替视觉验收。
