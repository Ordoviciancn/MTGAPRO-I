# 联机部署与玩家分发

## 玩家

解压完整客户端目录，运行 `MTGAPROⅠ.exe`，选择“连接远程服务器”。该模式不要求玩家安装 Forge、JDK 或 Node。大厅填写管理员提供的 `https://服务器域名` 或 `http://IP:端口`，连接后刷新房间、创建 BO1/BO3 房间，或加入已有房间。双方必须连接同一服务器。

当前没有随软件提供已上线的公共服务器地址。软件不能自动穿透所有路由器或替管理员购买、部署云服务器。

## 主持局域网

启动时选择“本机主持对局”，配置已构建的 Forge 工作区与 JDK。菜单“对局 → 服务器连接地址”显示本机 IPv4 地址和端口，同一网络的玩家填写该地址。主持者需要保持程序运行，并由自己允许 Windows 防火墙的相应入站连接；程序不自动修改防火墙。

## 专用 Windows 服务器

服务器保留完整项目、已构建的固定版本 Forge 和 JDK，构建桌面发布包后运行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/启动联机服务器.ps1 -JdkHome 'D:/Program Files/JDK' -Port 8787
```

该命令以无窗口服务器模式启动同一发行程序，监听所有 IPv4 接口。先检查 `/health` 和实际双玩家对局，再提供连接地址。专用服务器使用独立用户配置，可与普通桌面客户端同时运行；同一用户配置只能运行一个专用实例。需要停止时关闭对应进程；进程号由启动脚本输出。

公网部署需要公网 IP/端口映射，或支持 WebSocket 的 TLS 反向代理。推荐管理员将 HTTPS 域名反向代理到 `127.0.0.1:8787`，同时转发 `/forge` WebSocket；HTTPS 网页客户端必须使用 WSS。尚未代为配置域名、云主机、证书或 NAT。此版本没有账号系统、集中封禁、服务端存档或自动崩溃恢复，当前限制最多八个房间。

## 牌组保存

浏览器牌组保存在当前网站的本地存储中；桌面版通过受限接口写入用户数据目录 `deck-library.json`，不随临时服务端口变化而丢失。牌组不是自动同步到公共服务器的云存档。可导出备份后在另一台机器导入。
