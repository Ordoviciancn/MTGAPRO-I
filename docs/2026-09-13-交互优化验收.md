# 交互优化验收

- Forge 自动让过关闭原生阶段、结算表现延迟，保留所有规则决策；前端继续独立播放语义动画。
- 同座位重复快照不再投影、递增版本或广播，连续界面通知合并为一次待执行输入刷新。
- 拖拽每帧最多发布一次位置更新，使用合成位移；结束与取消时清除待执行帧。同步指令锁阻止同一渲染帧内重复提交。
- 牌手徽章采用分层金属、刻线和生命圆盘浮雕，点击不改变目标几何位置。
- `coinChoicePending` 由 Java 投影；落地与跳过只结束抛掷动作，双方硬币界面保留到引擎接受先后手选择。

验证：36 项应用测试、生产构建、真实网络施法及 BO3 三局四次换备通过。相同固定种子施法场景，视图消息由 195 降至 133（约 32%）；8 次指令的回执中位数约 31 ms，未据此宣称回执延迟显著改善。网络测试断言先后手作答前后硬币状态变化，并保留隐藏信息、身份、重复指令和重连检查。

浏览器自动化运行时当前无法初始化，本轮未完成视觉截图与浏览器拖拽回归；浮雕效果与拖拽流畅度仍需实际设备确认。发行包版本为 0.1.1，更新后重开客户端生效。
